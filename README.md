# Nivel

Nivel de burbuja e inclinómetro para el móvil, pensado para medir la inclinación de los bancos del gimnasio.

App: https://carlosmera10.github.io/nivel/

- **Banco**: ángulo del respaldo, con objetivo (−15° a 90°) y aviso al llegar (±1°).
- **Nivel**: burbuja en superficie plana y nivel de barra de canto.
- **Calibrar**: con el móvil plano en el suelo, para compensar cámara o funda.
