# Nivel

Nivel de burbuja e inclinómetro para el móvil, pensado para medir la inclinación de los bancos del gimnasio.

App: https://carlosmera10.github.io/nivel/

- **Banco**: ángulo del respaldo, con objetivo y aviso al llegar (±1°).
  - **Mis ejercicios**: cada ejercicio con su ángulo o rango (p. ej. curl inclinado 45–60°).
  - **Mis bancos**: guarda el ángulo de cada posición (agujero o muesca) y la app te dice qué posición usar.
- **Nivel**: burbuja en superficie plana y nivel de barra de canto.
- **Calibrar**: con el móvil plano en el suelo, para compensar cámara o funda.

## Abrir con un objetivo desde otra app

`https://carlosmera10.github.io/nivel/?ej=Curl%20inclinado&min=45&max=60` o `?angulo=30`.
Si el ejercicio no está en «Mis ejercicios», se añade.
